## معرفی

Mianboor یک اپلیکیشن اندروید برای ارائه‌ی کانفیگ‌های اشتراکی به کاربران است. طرز کار ساده و غیرگیج‌کننده است:

1. کاربر اپ را باز می‌کند و بلافاصله **پاپ‌آپ گیت** نمایش داده می‌شود
2. در پاپ‌آپ چهار گزینه دارد: **ورود کد اشتراک**، **خرید اشتراک**، **تست رایگان ۳ روزه** و **پشتیبانی**
3. شما (ادمین) با ابزار `panel/tools.py` کد عددی ۱۰ رقمی صادر می‌کنید و به مشتری می‌دهید
4. کاربر کد را وارد می‌کند؛ اگر در لیست کدهای تاییدشده‌ی شما بود، به بخش کانفیگ‌ها دسترسی پیدا می‌کند
5. کاربر بدون کد تاییدشده **هیچ دسترسی‌ای** به کانفیگ‌ها ندارد

### ویژگی‌ها

- 🎨 تم شیشه‌ای (Glassmorphism) نئون تیره با پالت بنفش/آبی — مطابق لوگوی MianBoor
- 🔐 کد اشتراک عددی با اعتبارسنجی از پنل گیت‌هاب (هش SHA-256 — کد خام هرگز ذخیره نمی‌شود)
- ⏱ اشتراک زمان‌دار: از لحظه‌ی فعال‌سازی کد شروع می‌شود و در تاریخ شمسی نمایش داده می‌شود
- 🎁 تست رایگان یک‌بار برای هر دستگاه (به‌صورت خودکار محدود می‌شود)
- 🛡 محافظت ضدحدس: بعد از ۵ خطا، یک دقیقه قفل می‌شود
- 📋 مدیریت کانفیگ: کپی، اشتراک‌گذاری و اتصال مستقیم (ارسال به کلاینت‌هایی مثل v2rayNG و Hiddify)
- 📴 کش آفلاین: آخرین کانفیگ‌ها بدون اینترنت هم نمایش داده می‌شوند
- 🇮🇷 رابط کاربری کاملاً فارسی و راست‌چین با فونت وزیرمتن
- ✨ لوگوی نئون متحرک، ستاره‌های فضایی و عناصر HUD (ادای احترام به تصویر مرجع)

## ساختار پروژه

```
Mianboor/
├── app/src/main/java/com/mianboor/app/
│   ├── AppConfig.kt          ← تنظیمات: آدرس پنل، تلگرام، کلید رمز، مدت تریال
│   ├── MainActivity.kt       ← اسپلش + نمایش پاپ‌آپ گیت
│   ├── GateDialogFragment.kt ← پاپ‌آپ اصلی (کد/خرید/تریال/پشتیبانی)
│   ├── DashboardActivity.kt  ← داشبورد کانفیگ‌ها (بعد از ورود کد)
│   ├── BuyActivity.kt        ← صفحه خرید و پلن‌ها
│   ├── SupportActivity.kt    ← صفحه پشتیبانی
│   ├── RemoteRepo.kt         ← دریافت کدها و کانفیگ‌ها از پنل
│   ├── Crypto.kt             ← هش SHA-256 + رمزنگاری XOR کانفیگ‌ها
│   ├── Prefs.kt              ← ذخیره‌سازی اشتراک و کش آفلاین
│   └── ...
├── panel/
│   ├── codes.json            ← کدهای تاییدشده (فقط هش)
│   ├── configs.json          ← کانفیگ‌های رمزنگاری‌شده
│   ├── tools.py              ← ابزار مدیریت پنل
│   └── README.md             ← راهنمای پنل
└── app/src/main/res/         ← رابط کاربری شیشه‌ای نئون
```

## شروع سریع (اندروید استودیو)

1. **Android Studio** (Narwhal یا جدیدتر) + **JDK 17** نصب کنید
2. پروژه را کلون یا دانلود کنید:
   ```bash
   git clone https://github.com/kopersheikhi-jpg/Mianboor.git
   ```
3. در اندروید استودیو: `File → Open` و پوشه‌ی `Mianboor` را باز کنید
4. صبر کنید تا Gradle Sync تمام شود (اولین بار چند دقیقه طول می‌کشد)
5. ساخت خروجی: `Build → Build App Bundles / APKs → Build APK(s)`
6. فایل APK در `app/build/outputs/apk/debug/` ساخته می‌شود

> خروجی release: `Build → Generate Signed Bundle / APK` و ساخت keystore مخصوص خودتان.

## مدیریت پنل (صدور کد و کانفیگ)

همه‌چیز از پوشه‌ی `panel/` مدیریت می‌شود — نیازی به آپدیت اپ نیست:

```bash
cd panel

# صدور کد ۳۰ روزه برای مشتری جدید
python3 tools.py add-code --days 30 --plan "اشتراک یک‌ماهه" --note "علی"

# افزودن کانفیگ جدید (همه‌ی کاربران مشترک می‌بینند)
python3 tools.py add-config --name "🇩🇪 آلمان — پرسرعت" --uri "vless://..."
```

بعد از تغییر فایل‌ها، آنها را به گیت‌هاب push کنید (یا در خود گیت‌هاب ویرایش کنید) — اپ‌ها
با دکمه‌ی بروزرسانی یا در اجرای بعدی، اطلاعات جدید را می‌گیرند.

جزئیات بیشتر: [`panel/README.md`](panel/README.md)

## نحوه‌ی اتصال کاربران

اپلیکیشن کانفیگ‌ها را با دکمه‌ی «اتصال» به کلاینت‌های نصب‌شده (v2rayNG، Hiddify، NekoBox و…)
ارسال می‌کند. اگر کلاینتی نصب نباشد، کانفیگ به‌طور خودکار کپی می‌شود تا در برنامه‌ی دلخواه
جای‌گذاری شود. اگر می‌خواهید اپ مستقیماً خودش کانکت شود (بدون اپ ثالث)، می‌توان هسته‌ی
Xray را در فاز بعدی به همین پروژه اضافه کرد.

## امنیت

- کد اشتراک فقط به‌صورت **هش SHA-256** در ریپو ذخیره می‌شود؛ لو رفتن ریپو = لو رفتن کدها نیست
- کانفیگ‌ها با **XOR + Base64** رمزنگاری می‌شوند تا از خزنده‌های خودکار پنهان بمانند
- بعد از ۵ تلاش ناموفق، ورود کد ۶۰ ثانیه قفل می‌شود
- ⚠️ توکن گیت‌هاب خود را بعد از استفاده **حتماً revoke کنید** و هرگز در کد یا README قرار ندهید
- برای امنیت بیشتر در مقیاس بزرگ: انتقال پنل به یک بک‌اند خصوصی با احراز هویت
